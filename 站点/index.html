这套东西是怎么跑起来的

所有服务以独立 Docker Compose 单元部署在 /opt/cloudlab/ 下，数据用命名卷或 bind 目录持久化。 对外只暴露 NPM 的 80/443，其余端口由安全组和 iptables 收敛；Prometheus 与 Node Exporter 仅在内网可见。 每天 03:30 由 crontab 触发备份脚本，打包配置与数据卷并保留 7 天。
